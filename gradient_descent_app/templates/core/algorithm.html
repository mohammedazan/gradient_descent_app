Comment fonctionne l'algorithme Gradient Descent ?

L'algorithme Gradient Descent est une méthode d'optimisation utilisée pour trouver les meilleures valeurs des paramètres (θ) qui minimisent la fonction de coût (Cost Function).

Étapes de l'algorithme :
  1. Initialisation : Commencer avec des valeurs aléatoires pour les paramètres
  2. Calcul des prédictions : Utiliser les paramètres actuels pour prédire
  3. Calcul du coût : Comparer les prédictions aux valeurs réelles
  4. Calcul du gradient : Calculer la direction d'amélioration
  5. Mise à jour des paramètres : Déplacer les paramètres dans la direction d'amélioration
  6. Itération : Répéter les étapes jusqu'à convergence
Équation de mise à jour
θ = θ - α × ∇J(θ)
Où :
θ = paramètres
α = taux d'apprentissage
∇J(θ) = gradient de la fonction de coût
