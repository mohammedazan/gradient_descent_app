Conseils pour améliorer les résultats
Si les performances sont faibles :
  • Essayez un taux d'apprentissage différent (plus grand ou plus petit)
  • Augmentez le nombre d'itérations
  • Assurez-vous d'appliquer la normalisation aux données
  • Vérifiez la qualité des données originales
Si l'algorithme ne converge pas :
  • Réduisez le taux d'apprentissage
  • Assurez-vous d'appliquer la normalisation
  • Vérifiez la présence de valeurs aberrantes dans les données
  • Essayez une méthode de normalisation différente
