Conseils pour obtenir les meilleurs résultats
Traitement des valeurs manquantes :
  • Si les valeurs manquantes sont peu nombreuses (<5%), utilisez la suppression des lignes
  • Pour les données numériques, le remplissage par la moyenne est une bonne option
  • Utilisez une valeur constante si vous connaissez une valeur logique pour le remplissage
Normalisation :
  • La normalisation standard convient aux données à distribution normale
  • Min-Max convient quand vous voulez préserver les relations proportionnelles
  • La normalisation est très importante pour assurer une convergence rapide de l'algorithme
